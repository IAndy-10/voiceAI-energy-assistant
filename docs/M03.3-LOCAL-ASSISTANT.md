# M03.3 — navegación y asistente dual

`/demo` se organiza en este orden: **Datos y accesos**, **Indicadores** y **Asistente IA**. La primera pestaña carga el snapshot y conserva token, archivo activo y estado visibles también en la cabecera. Cambiar de pestaña no recarga la página.

El asistente tiene dos modalidades. Con **Usar OpenAI** apagado usa `POST /agent/local-chat`: un intérprete determinista y limitado para costo/consumo anual, ranking, solar, chiller y brechas. No llama proveedores ni finge una respuesta de OpenAI. Con el interruptor encendido y el servidor correctamente configurado usa `POST /agent/chat` con los límites existentes.

Al cambiar de modalidad o de snapshot se limpia el historial visible y los resultados. El snapshot sigue siendo sólo de memoria y debe cargarse luego de recrear `energy-api`.

```powershell
docker compose up -d --build --force-recreate --no-deps energy-api
.\.venv\Scripts\python.exe -m pytest -q -p no:cacheprovider
```

No se eliminan volúmenes: `agent-usage` conserva el ledger. Si Docker no está disponible, ejecute el comando anterior en un terminal con acceso al daemon; el dashboard no se reconstruye ni se modifica.
