# M03.7 — Hardening y refinamiento final

## SEC-001: auditoría de credenciales

- `.env`, `.env.*`, `Datos/`, `data/`, libros Excel y snapshots generados están ignorados por Git.
- `.dockerignore` excluye `.env`, datos privados, snapshots, Git y entornos virtuales; la imagen `energy-api` copia sólo dependencias y `energy_tools/`.
- `compose.yaml` referencia variables de entorno; no contiene valores de claves. No use `docker compose config` en una consola cuya salida se vaya a compartir, porque Compose expande las variables.
- Los endpoints de snapshot, Energy Tools y agentes usan Bearer y comparación de secretos en servidor. `/health`, `/tools` y `/demo` no devuelven datos del snapshot.
- Logs de proveedor conservan únicamente categoría, clase, estado, código y request ID; no prompt, snapshot, resultados, headers ni claves.
- El volumen `agent-usage` mantiene sólo contadores/tokens/USD; no contiene conversaciones ni datos del cliente. No debe eliminarse como parte de la demo.

### Rotación

Si una clave fue expuesta, revóquela en OpenAI Platform y genere una nueva. Actualice manualmente sólo `.env` local, reinicie exclusivamente `energy-api` y no copie la clave a terminales compartidos, documentación, issues o capturas. La auditoría no lee ni imprime `.env`.

## UX

Las burbujas del chat usan altura de contenido (`min-height: 0`, filas de grilla de contenido y alineación individual), ancho máximo acotado y scroll interno del historial. El formulario queda fuera del historial. Las respuestas del asistente permiten sólo Markdown básico tras escapar primero HTML: negrita, listas, párrafos, saltos y código inline. No se interpreta HTML recibido.

El indicador OpenAI muestra, sólo en modalidad OpenAI, modelo, consultas acumuladas, gasto conocido, presupuesto restante y costo de la última respuesta cuando existe. Las cifras provienen de `GET /agent/status` y de `usage` de la respuesta; no se calculan ni inventan en el navegador.

## Verificación local

```powershell
.\.venv\Scripts\python.exe -m pytest -q -p no:cacheprovider
docker compose up -d --build --force-recreate --no-deps energy-api
```

No ejecutar `docker compose config` para validar una sesión real. Tras reconstruir, abra `http://127.0.0.1:8000/demo`, cargue el snapshot y compruebe las tres pestañas, burbujas cortas, scroll y ambas modalidades. El snapshot se carga de nuevo tras recrear `energy-api`; el volumen `agent-usage` se conserva.
